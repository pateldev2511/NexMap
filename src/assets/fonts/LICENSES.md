# Bundled fonts — licenses & provenance

NexMap self-hosts its fonts so the app ships zero runtime network dependencies
(CSP `font-src 'self'`). Each file is the **latin-subset, variable-weight woff2**
build published on Google Fonts, redistributed here under the SIL Open Font
License, Version 1.1 — which explicitly permits bundling and redistribution.

| `spacegrotesk-latin.woff2` | Space Grotesk | Florian Karsten | https://github.com/floriankarsten/space-grotesk | OFL-1.1 |
| `jetbrainsmono-latin.woff2` | JetBrains Mono | JetBrains | https://github.com/JetBrains/JetBrainsMono | OFL-1.1 |

The full SIL Open Font License 1.1 text is available at
https://openfontlicense.org/. No Reserved Font Names are used by these builds,
and the files are unmodified subsets of the upstream releases.
