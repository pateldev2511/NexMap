# Keyboard shortcuts

On a Mac, use <kbd>⌘</kbd> wherever this page says <kbd>Ctrl</kbd>, and
<kbd>Option</kbd> for <kbd>Alt</kbd>. You can see this list in the app too:
**More → Keyboard shortcuts**, or press <kbd>?</kbd>.

## Files

| Keys | Action |
| --- | --- |
| <kbd>Alt</kbd>+<kbd>N</kbd> | New project |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Open a `.nexmap` file |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Export |

## Editing

| Keys | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Undo / redo |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Select everything |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>X</kbd> / <kbd>V</kbd> | Copy / cut / paste (devices, spreadsheet rows or an image) |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Duplicate the selection |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd> | Delete the selection |
| Arrow keys | Nudge the selection (hold <kbd>Shift</kbd> for bigger steps) |
| <kbd>Ctrl</kbd>+<kbd>G</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> | Group / ungroup |
| <kbd>Ctrl</kbd>+<kbd>]</kbd> / <kbd>Ctrl</kbd>+<kbd>[</kbd> | Bring forward / send backward |
| Double-click a label | Edit its text |
| Double-click empty canvas | Add a device right there |

## Tools

| Key | Tool |
| --- | --- |
| <kbd>V</kbd> | Select |
| <kbd>Q</kbd> | Lasso select |
| <kbd>H</kbd> | Pan |
| <kbd>C</kbd> | Connect |
| <kbd>T</kbd> | Text note |
| <kbd>R</kbd> | Zone / shape |
| <kbd>Esc</kbd> | Cancel, then deselect, one step at a time |

## Moving around

| Keys | Action |
| --- | --- |
| Scroll, or two-finger drag | Pan |
| <kbd>Space</kbd> + drag, or right/middle-drag | Pan |
| <kbd>Ctrl</kbd> + scroll, or pinch | Zoom |
| <kbd>Ctrl</kbd>+<kbd>+</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | Zoom in / out |
| <kbd>Ctrl</kbd>+<kbd>0</kbd> | Fit everything on screen |
| <kbd>2</kbd> | Zoom to the selection |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Find a device |
| Hold <kbd>Alt</kbd> while dragging | Ignore the snap-to-grid |

## Everything else

| Keys | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Command palette: type what you want to do |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd> | Auto-layout (tidy up) |
| <kbd>Tab</kbd> | Move to the next device |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | Select the device you've moved to |
| <kbd>?</kbd> | Show the shortcut list |
